# GPS時計ファームウェア

PIC16F15313マイコンを使用したGPS時計のファームウェアです。GPSモジュールからUARTでNMEAメッセージを受信し、HT16K33A搭載の5×21 LEDマトリクスディスプレイに時刻を表示します。

---

## 特徴

- GPS モジュールの `$GPRMC` センテンスを解析して時刻を取得
- UTC から日本標準時（JST = UTC+9）に自動変換
- 5×21(5行21列) LEDマトリクス（HT16K33A）に **HH:MM** 形式で時刻を表示
- コロン（:）が1秒ごとに点滅
- GPS から時刻を取得できない場合はタイマーで1秒を計測し、秒を更新するフォールバック動作
- 3つのステータス LED で受信状態を表示
- I2C 通信エラー時の自動リカバリ機能

## ピン配置

| ピン番号 | 信号名 | 機能 | 接続先 |
|---------|--------|------|--------|
| RA0 | UART_TX | UART 送信 | GPSモジュール RX |
| RA1 | UART_RX | UART 受信 | GPSモジュール TX |
| RA2 | LED | 動作確認用ステータスLED | LED（アノード側） |
| RA4 | SCL | I2C クロック | HT16K33A SCL |
| RA5 | SDA | I2C データ | HT16K33A SDA |

> **注意：** RA4 / RA5 はオープンドレイン出力です。プルアップ抵抗（4.7kΩ推奨）を VCC に接続してください。

## 周辺パーツの接続

### GPS モジュール（UART接続）

GPSモジュールは UART（非同期シリアル）で接続します。

```
PIC16F15313       GPS モジュール
  RA0 (TX)  ───── RX
  RA1 (RX)  ───── TX
  GND       ───── GND
  VCC       ───── VCC (3.3V または 5V)
```

- ボーレート：**9600 bps**、8bit、パリティなし、ストップビット1（9600 8N1）
- PIC16F15313 の動作電圧は 1.8〜5.5V です。GPSモジュールの電源電圧および I/O レベルに合わせてください（例：PICを3.3Vで動かす場合に5V出力のGPSモジュールを接続するなら電圧レベル変換が必要です）。

### HT16K33A LEDマトリクスドライバ（I2C接続）

HT16K33A は I2C で接続します。I2C アドレスは `0x70`（A0〜A2 すべて未接続）です。

```
PIC16F15313       HT16K33A
  RA4 (SCL) ──┬── SCL
              └── 4.7kΩ ── VCC
  RA5 (SDA) ──┬── SDA
              └── 4.7kΩ ── VCC
  GND       ───── GND
  VCC       ───── VCC
```

- HT16K33A の `A0`〜`A2` ピンは、ダイオードと抵抗を介して指定の ROW/COM ピンに接続するとそのビットが 1 になり、未接続の場合は 0 になります。A0〜A2 をすべて未接続にするとアドレス `0x70`（アドレスビットすべて 0）になります。
- HT16K33A に 5×21 LEDマトリクスを接続してください（行：5本、列：21本）。

### 動作確認用 LED（RA2）

```
PIC16F15313
  RA2 ──── 抵抗（330Ω程度） ──── LED ──── GND
```

### 全体配線イメージ

```
       ┌─────────────────────┐
       │    PIC16F15313      │
       │                     │
  GPS─────RA1(RX)  RA4(SCL)──┤──[4.7kΩ]──VCC
  GPS─────RA0(TX)  RA5(SDA)──┤──[4.7kΩ]──VCC
              │                │       │
              │         ┌──────┘  HT16K33A
              │         └──────── SCL / SDA
       LED────RA2              │
              │           LEDマトリクス
             GND              GND
```

## ステータス LED の表示

LEDマトリクス上の3つの LED で受信状態を示します。ディスプレイ左から **LED1・LED2・LED3** と呼称します。

| LED | 点灯条件 |
|-----|---------|
| LED1 | `$GPRMC` センテンスを受信した |
| LED2 | `$GPRMC` センテンスから時刻情報を取得した |
| LED3 | `$GPRMC` のステータスが有効（`A`）である |

### 通常の点灯シーケンス

GPSモジュールの電源 ON 後、測位が完了するまでに次の順序で点灯します。

```
GPS起動直後  → LED1 点灯（RMC受信開始）
          ↓
時刻情報取得 → LED2 点灯
          ↓
 ステータス有効(A) → LED3 点灯
```

### タイマーフォールバック動作

一度 `$GPRMC` から時刻情報を取得した後、何らかの理由で時刻情報が取得できなくなった場合：

- **LED3 のみ点灯**した状態を維持します
- 内部タイマーで **1秒を計測**し、秒を更新し続けます（GPSなしで時刻を刻み続けます）
- GPS の時刻情報が再び取得できるようになると通常動作に戻ります

GPS未接続または測位前は LED が消灯した状態から順に点灯していきます。

## ビルド・書き込み方法

1. MPLAB X IDE でプロジェクトを開く
2. XC8 コンパイラが設定されていることを確認する
3. **Production → Make and Program Device** でビルドおよび書き込みを実行する
4. プログラマ（PICkit 4 など）を MCLR・ICSP ピンに接続して書き込む
