# GPS時計ファームウェア

PIC16F15313マイコンを使用したGPS時計のファームウェアです。GPSモジュールからUARTでNMEAメッセージを受信し、HT16K33A搭載の5×21 LEDマトリクスディスプレイに時刻を表示します。

---

## 特徴

- GPS モジュールの `$GPRMC` センテンスを解析して時刻を取得
- UTC から日本標準時（JST = UTC+9）に自動変換
- 7×21 LEDマトリクス（HT16K33A）に **HH:MM** 形式で時刻を表示
- コロン（:）が1秒ごとに点滅
- 3つのステータス LED で受信状態を表示
- I2C 通信エラー時の自動リカバリ機能

| 項目 | 内容 |
|------|------|
| マイコン | PIC16F15313 |

## ピン配置

| ピン番号 | 信号名 | 機能 | 接続先 |
|---------|--------|------|--------|
| RA0 | UART_TX | UART 送信 | GPSモジュール RX |
| RA1 | UART_RX | UART 受信 | GPSモジュール TX |
| RA2 | LED | 動作確認用ステータスLED | LED（アノード側） |
| RA4 | SCL | I2C クロック | HT16K33A SCL |
| RA5 | SDA | I2C データ | HT16K33A SDA |

> **注意：** RA4 / RA5 はオープンドレイン出力です。プルアップ抵抗（4.7kΩ推奨）を VCC に接続してください。

## 周辺パーツの接続

### GPS モジュール（UART接続）

GPSモジュールは UART（非同期シリアル）で接続します。

```
PIC16F15313       GPS モジュール
  RA0 (TX)  ───── RX
  RA1 (RX)  ───── TX
  GND       ───── GND
  VCC       ───── VCC (3.3V または 5V)
```

- ボーレート：**9600 bps**、8bit、パリティなし、ストップビット1（9600 8N1）
- PIC16F15313 の動作電圧は 1.8〜5.5V です。GPSモジュールの電圧レベルに合わせてください。5V のモジュールを使用する場合は電圧レベル変換が必要です。

### HT16K33A LEDマトリクスドライバ（I2C接続）

HT16K33A は I2C で接続します。I2C アドレスは `0x70`（A0〜A2 すべて GND）です。

```
PIC16F15313       HT16K33A
  RA4 (SCL) ──┬── SCL
              └── 4.7kΩ ── VCC
  RA5 (SDA) ──┬── SDA
              └── 4.7kΩ ── VCC
  GND       ───── GND
  VCC       ───── VCC
```

- HT16K33A の `A0`〜`A2` ピンをすべて GND に接続するとアドレス `0x70` になります。
- HT16K33A に 7×21 LEDマトリクスを接続してください（行：5本、列：21本）。

### 動作確認用 LED（RA2）

```
PIC16F15313
  RA2 ──── 抵抗（330Ω程度） ──── LED ──── GND
```

### 全体配線イメージ

```
       ┌─────────────────────┐
       │    PIC16F15313      │
       │                     │
  GPS─────RA1(RX)  RA4(SCL)──┤──[4.7kΩ]──VCC
  GPS─────RA0(TX)  RA5(SDA)──┤──[4.7kΩ]──VCC
              │                │       │
              │         ┌──────┘  HT16K33A
              │         └──────── SCL / SDA
       LED────RA2              │
              │           LEDマトリクス
             GND              GND
```

## ステータス LED の表示

LEDマトリクス上の3つの LED で受信状態を示します。

| LED | 点灯条件 |
|-----|---------|
| LED1 | `$GPRMC` センテンスを受信した |
| LED2 | 時刻データが含まれている |
| LED3 | GPS測位有効（Fix取得済み） |

GPS未接続または測位前は LED が消灯し、約5秒ごとに表示がクリアされます。

## ビルド・書き込み方法

1. MPLAB X IDE でプロジェクトを開く
2. XC8 コンパイラが設定されていることを確認する
3. **Production → Make and Program Device** でビルドおよび書き込みを実行する
4. プログラマ（PICkit 4 など）を MCLR・ICSP ピンに接続して書き込む
